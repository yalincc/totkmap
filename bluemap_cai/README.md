# 蓝图素材库（开发中）

**这是老大于 2026-11-14 起手工搜集的《塞尔达传说：王国之泪》蓝图素材，筛选整理后放到网站供用户下载——不是临时文件，不要删除本目录。**

## 用途

- 开发阶段手工搜集的真实玩家蓝图（`.cai` 文件），作为「蓝图分享 / 精选蓝图工坊」功能的候选素材源。
- 整理筛选后会发布到网站供用户下载；目前**尚未上线**。
- 与已上线的内置预设库（`app/data/blueprints-preset.js`，10 款）和浏览器本地蓝图库（localStorage）是三套独立机制，勿混。

## 文件格式

- 标准 `.cai`：文件头 `CmbAct v2`，有效载荷 6688 字节，与存档 30 槽蓝图数据同源。
- 命名规则：`blueprint_<时间戳>.cai`，持续补充中。
- 前端代码**不运行时引用本目录**——改动它不影响网页显示与存档写回，删它也不会报错（但会丢失素材）。
