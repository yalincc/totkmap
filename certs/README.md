# TOTKNavi 手机防息屏 HTTPS 证书说明

> 本文件说明 TOTKNavi 的【手机防息屏（Https）】功能如何配置。
> **你可以把本文件直接发给 AI（豆包 / ChatGPT 等），说"按这个文档帮我处理 HTTPS 证书问题"，AI 会照着步骤替你完成。**

---

## 0. 这是可选功能吗？

**是。**【手机防息屏（Https）】只是优化体验：勾选后手机镜像页通过 HTTPS 访问，浏览器允许 **Screen Wake Lock**，手机屏幕**保持常亮不锁屏**。

**不勾选、不装证书、不配 HTTPS，完全不影响定位导航核心功能**——只是手机屏可能按正常息屏（约 5 分钟自动锁屏，需手动点亮）。

## 1. 技术原理（30 秒看懂）

| 概念 | 说明 |
|---|---|
| 为什么需要 HTTPS | 浏览器规定 Screen Wake Lock（防息屏 API）**只在安全上下文可用**——即 HTTPS 或 localhost。局域网 http 访问时该 API 被禁用 |
| 自签 CA 结构 | 两层：**rootCA.pem**（根证书，手机信任它，10 年有效）+ **server.pem**（服务器证书，给 8766 端口用，398 天） |
| 为什么服务器证书 398 天 | iPhone 对 TLS 服务器证书有硬限制：有效期超过 398 天一律拒绝。这是苹果的规定，不是我们能选的 |
| 服务器证书绑定 IP | server.pem 的 SAN 写死了**生成它那台电脑的局域网 IP**（如 192.168.31.234）。换电脑或 IP 变了，证书不匹配，HTTPS 会报错 |
| 为什么能"http + https 共存" | xnavi 核心在 8766 端口自动嗅探：TLS 握手走 HTTPS 通道，普通 http 请求走明文通道。所以手机用 https 防息屏，在线地图 / 旧书签 http 访问全部照常 |

## 2. 包内文件

解压后 `certs/` 目录（本发布版只含以下三个文件，**不含私钥**）：

| 文件 | 作用 |
|---|---|
| `rootCA.pem` | 手机安装的根证书（每台手机装一次，10 年有效） |
| `gen-cert.ps1` | 一键重签脚本：生成/刷新服务器证书，自动检测本机局域网 IP |
| `README.md` | 本说明 |

## 3. 快速开始（全程 3-5 分钟）

### 3.1 电脑端（每台要用的电脑各做一次）

1. 打开 TOTKNavi → 设置 → 勾选【手机防息屏（Https）】→ 保存；
2. 如果 `certs/` 下**没有** `server.pem`（发布版本来就不带），先运行 `certs\gen-cert.ps1` 生成本机证书：
   - 右键 `gen-cert.ps1` → 用 PowerShell 运行（或 `powershell -File gen-cert.ps1`）；
   - 脚本自动检测本机局域网 IP 并签发，几秒钟完成；
3. 正常点击「开始定位」。核心日志出现 `API -> https://127.0.0.1:8766/pos (http + https dual mode)` 即成功。

> 首次运行脚本时若目录里没有 `rootCA.key`，会生成**新的根证书**——此时手机需要按 3.2 重新装一次 rootCA.pem。

### 3.2 手机端（每台手机装一次，10 年有效）

1. 手机与电脑连**同一 WiFi**；
2. 电脑上临时提供证书下载：运行 `certs\serve-cert.ps1`（会在 8443 端口起一个临时 HTTPS 服务，终端会显示一个二维码）；
3. 手机扫码打开 `https://<电脑IP>:8443/`，下载 `rootCA.pem`；
4. 按手机系统安装证书（**各家手机步骤不同**，搜索"iPhone 安装描述文件 信任证书" / "安卓 安装 CA 证书"，全程 3-5 分钟）：
   - **iPhone**：设置 → 通用 → VPN 与设备管理 → 安装描述文件；再到 设置 → 通用 → 关于本机 → 证书信任设置 → 开启对该根证书的完全信任；
   - **Android**：设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书；
5. 手机浏览器打开 `https://<电脑IP>:8766/botw/?follow=1&game=totk`，确认地址栏有锁标记（不报证书错误）；
6. 之后点开镜像页放着即可，屏幕保持常亮。

### 3.3 换电脑 / IP 变了 / 证书过期

- 在新电脑的 `certs/` 目录跑一次 `gen-cert.ps1`，自动检测新 IP 重新签发；
- 服务器证书 398 天过期后同样重跑一次；
- **手机不用重新安装 rootCA**（只要重签时复用了同一个根，见 3.1 第 2 步的说明）。

## 4. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 手机访问 https 报"证书无效 / 不安全" | server 证书 SAN 不含当前访问 IP：在电脑上重跑 `gen-cert.ps1` 后再试 |
| 勾选防息屏后日志刷 `TLS handshake error` | 这是 GUI 端口探测的正常噪声，双协议下已静默处理；只有大量 `client sent an HTTP request` 才需要看 |
| 不勾选防息屏，其他功能都正常 | 正常。此功能纯可选 |
| 换手机了 | 新手机按 3.2 装一次 rootCA 即可，电脑端无需任何操作 |

## 5. 给 AI 的一句话

> 帮我在 Windows 上配置 TOTKNavi 的手机防息屏 HTTPS 证书：先看 `certs/README.md`，然后运行 `certs/gen-cert.ps1` 生成证书，再帮我用 `certs/serve-cert.ps1` 起临时下载服务，告诉我手机怎么装 rootCA.pem。

## 6. 安全说明

- 只读内存、不修改游戏、不上传数据；
- 证书仅用于局域网内手机访问镜像页；`server.key` 仅保存在生成它的那台电脑上，发布包不含私钥；
- 本方案是**局域网自签证书**，不是公网 CA，请勿把它当作公网 HTTPS 使用。
