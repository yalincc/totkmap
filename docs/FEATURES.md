# TOTKmap 功能详解

> 本文件是仓库 `README.md`「核心功能」表的展开版。README 只留一句话简介，完整说明在这里。
> 界面设计规范另见 [UI-MANUAL.md](UI-MANUAL.md)。

## 地图与图层

**三层地图**：天空 / 地上 / 地下一键切换，各自独立的标点、地名与瓦片；左侧层按钮可锁定当前层。

**高清瓦片**：游戏内等高线地形风格瓦片，按层选格式（WebP q80），最大 1:1 像素仍清晰。
z7 瓦片未纳入仓库（受托管平台文件数限制），放大到 z7 尺寸时由 z6 瓦片 2× 缩放实现，清晰度等价 z6。

**多图层同显**：位置 / 收集 / 装备 / 地点 / 怪物五大类可任意勾选组合，一键全选 / 清空。

**大分类一键全选**：左侧每个大分类标题右侧有按钮，三态显示「全选本组 → 全选（2/14）→ 清空本组」，
按图层分别记忆。

**官方地名**：1312 处官方中文地名直接印在地图上（objmap Location 坐标），随缩放分层显隐，自动防重叠。

**龙的轨迹**：四条龙飞行轨道独立图层，**数据直接来自游戏本体 ROMFS 官方轨道**
（精确贝塞尔曲线 + 真实飞行高度）：白龙（低空 / 高空双轨大圈 + 2 条联络轨 + 初岛支线，约 33km）、
奥尔龙（14.3km）、费罗龙（8.6km）、聂尔龙（10.4km）。入口在侧栏「位置」大组末尾的「龙的轨迹」小分类，
点一下显示 / 隐藏，跨层通用。**实线 = 当前层域内的轨迹、虚线 = 另一层域**
（地上看地下段用虚线，地下看地上段用虚线），沿线箭头指示飞行方向。

## 收集与进度

**官方大世界宝箱**（v2.7.0 起）：收录 1,334 个官方大世界宝箱，按三层世界分层渲染，
可单独开关；已开启的宝箱计入探索度，与游戏存档实时对齐。旧版 252 条实验性图鉴数据已隐藏，避免重复计数。

**存档同步**：自动读取《王国之泪》`progress.sav`，解析全程在本地完成，不上传任何数据。
配合 TOTKNavi 时存档变动会自动刷新；也可手动加载存档文件。内置「同步存档 · 帮助」
（模拟器 / 游戏版本、存档位置、加载方式）。

**探索度面板**：按「探索 / 任务 / 收集 / 讨伐」四大组双列展示完成数，共 21 类
（含 6 类 Boss 讨伐、地洞 / 洞穴 / 井、残旧地图、设计图石板、大世界宝箱），点击展开 / 收起。
左侧大分类标题带动态进度徽标，直接显示「已完成 / 总数」。

**中英双语**：设置面板一键切换界面语言；神庙 / 鸟望台 / 树根 / 克洛格等点位显示官方英文名，
长文攻略保持中文。攻略文本与代码解耦（`app/data/guides/*.json`），改文字不用动代码。

**完成标记**：点击标点查看详情，可标记为已完成，进度保存在浏览器本地。

**自定义标记**：在地图空白处添加带名称的个人标记。

## 材料查询

**材料刷点**：110 种材料共 44,279 个刷点（地表 / 地底 / 天空全覆盖），勾选即在地图上显示；
supercluster 聚合 + 数量徽标，最大缩放到 z7 尺寸时逐点显示、每个材料点可点。

**材料详情卡**：256×256 高清图标 + 用途标签（升级素材 / 料理材料 / 强化材料）+
导航 / 收集 / 标记完成三按钮；收集后自动定位下一未采集点。

**性能优化**：聚合半径随缩放级别动态调整（100% = 96px → 800% = 128px）+ 移动防抖，
地下 12,000+ 刷点场景拖动依旧流畅。

## 搜索与链接

**搜索定位**：按神庙 / 地名 / 任务 / 物品名搜索，回车直达并居中放大；材料 Tab 内独立搜索。

**URL 深链**：`?actor=<物品名>` 直达材料刷点，`?q=<关键词>` 自动搜索。

## 移动端

窄屏默认收起面板，触控缩放平移，详情卡自动变底部抽屉。配合 TOTKNavi 的手机镜像功能，
扫码即可在手机 / 平板上实时跟随（需本地离线地图包）。
