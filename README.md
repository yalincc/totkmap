# TOTKMAP · 塞尔达传说：王国之泪 互动地图

本地离线版《王国之泪》互动地图，界面复刻游民星空互动地图风格，适配手机与电脑。

## 功能

- **三层地图**：天空 / 地上 / 地下，一键切换，各自独立的标点与地名
- **高清游戏风格瓦片**：地图瓦片来自游戏离线渲染数据（objmap-totk），
  地上/天空/地下三层均为游戏内等高线地形风格，支持放大 7 级（约 2.4 万像素宽），
  100% 还原游戏地图观感
- **图层工具**：搜索框下方「全选图层 / 清空图层」+ 图层计数，一键显隐当前层所有分类
- **分类筛选**：位置 / 收集 / 装备 / 地点 / 怪物 五大类，双列展示，点选即显隐；
  分类右侧只显示该分类标点总数（gamersky 式），不显示分数
- **存档同步进度**：侧栏底部「📂 从存档加载进度…」（旁有 ? 可查看存档位置与
  加载方法，存档路径一键复制），上传《王国之泪》的 progress.sav，自动读取
  游戏真实收集进度（鸟望台、神庙、树根、龙之泪、克洛格、双倍克洛格、魔犹伊、
  贤者的遗志、卡邦达立牌等），支持把存档文件直接拖进面板加载，
  解析全程在本机完成，不会上传
- **探索度**：加载存档后，侧栏「探索度」显示关键收集项完成进度与统一长度的
  金色进度条（神庙 8/152、龙之泪 0/12、克洛格 4/800…），分数右对齐，
  点击标题可展开/收起，不显示百分比
- **完成标记**：点击标点查看详情，可标记为已完成，进度保存在本地浏览器
- **搜索定位**：输入神庙/地名/任务/物品名称，搜索结果一键跳转
- **显示标点名称**：开关控制地图上的标点名称标签
- **新增标点**：在地图上点击空白处，添加自定义标记（保存在本地）
- **详情弹窗**：点位名称、分类、攻略说明、一键复制坐标
- **地名风格**：区域名直接印在地图上（暖白地图字色带深色描边，贴合游戏内地图），
  随缩放层级显示不同详略的地名
- **移动端适配**：窄屏默认收起面板，触控缩放平移

## 打开方式

双击 `index.html` 即可使用。同步存档时选择游戏存档目录下的
`progress.sav` 文件（Ryujinx：`bis\user\save\<用户>\0\slot_XX\progress.sav`），
解析全部在本地完成，不上传任何数据。
