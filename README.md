# TOTKMAP · 塞尔达传说：王国之泪 互动地图

《塞尔达传说：王国之泪》简体中文互动地图，支持天空/地上/地下三层切换、多图层同显、收集进度追踪、材料刷点查询与实时角色导航。

[中文](README.md) | [English](README.en.md)

> **两条产品线，各自独立发版、互不影响**：
> **地图**（本条线，`totkmap-vX.Y.Z`）与**导航程序 TOTKNavi**（`totknavi-vX.Y.Z`）在 Releases 里按前缀区分，可任意组合使用。

## 直接使用

| 方式 | 操作 |
|---|---|
| **在线版** | 打开 <https://totk.yalin.site/> |
| **本地 / 离线使用** | 下载地图包 `TOTKmap-vX.Y.Z.zip`（[Releases](https://github.com/yalincc/totkmap/releases) 里 `totkmap-` 前缀），解压后浏览器打开 `app/index.html`；瓦片 / 图标 / 数据全部本地，断网可用 |
| **自行部署** | 把 `app/` 整个文件夹放到任意静态服务器（Nginx / EdgeOne Pages / GitHub Pages 等）根目录，站点根目录指向 `app/` 内容即可。推荐用静态服务器打开（如 VS Code Live Server、`python -m http.server`），瓦片加载比 `file://` 更快 |

> 完成进度、自定义标记、图层选择自动保存在浏览器本地存储中，关页不丢。

## 项目结构

> **入库边界**：仓库只保留**网页源码与数据产物**、**定位服务源码**、**人工任务档案**。数据流水线工具、过程数据、备份、发布包一律不入库（见下方"不入库"清单），可复现产物已打进 `app/`。

```
TOTKmap/
├── app/                            ← 网页地图（下载 / 部署只需这个文件夹）
│   ├── index.html                  ← 入口页面
│   ├── sw.js                       ← 离线缓存（Service Worker）
│   ├── assets/                     ← 图标、材料图片
│   ├── css/  js/  data/            ← 样式、逻辑、地图数据（含任务卡片/流程/数据产物）
│   ├── vendor/                     ← 第三方库（Leaflet 等）
│   └── tiles_obj/                  ← 三层地图瓦片（天空 / 地上 / 地下）
├── tasks/manual/                   ← 任务人工档案（YAML，任务卡片数据源，build 时并入 app/data/task-plan.js）
├── totknavi/                       ← 定位核心工程（known 秒锁 / 指针链 / 自愈，双平台统一）
├── totknavi-gui/                   ← 桌面导航程序 TOTKNavi-GUI（Wails 工程）
├── README.md                       ← 本说明
├── CHANGELOG.md                    ← 版本变更记录
└── .gitignore                      ← 入库边界定义
```

**不入库**（本地保留，均为过程产物或可重建）：
- `tools/` — 数据流水线 / 瓦片与任务构建工具脚本（生成产物已打进 `app/`）
- `主线/情节/神庙/迷你挑战改版数据/`、`数据校对/` — 任务校对过程数据（卡片数据已合入 `app/data/task-plan.js`）
- `归档/`、`tasks/manual-备份-*/`、`report/` — 历史文档（含 live 系列退役引擎）、导入前备份、临时报告
- `release/`、`certs/` — TOTKNavi 桌面发布包与证书（发布时单独分发）

**下载指引**（两条线分开下，按需组合）：
- 只要地图 → Releases 里下载 **`totkmap-vX.Y.Z.zip`**（或直接用在线版）
- 要桌面实时导航 → 再下载 **`totknavi-vX.Y.Z.zip`**，解压后把地图包的 `app/` 放到 `TOTKnavi.exe` 同目录即可联动
- 两者版本独立：新版地图配旧版导航、旧版地图配新版导航都能正常工作

## 实时角色导航（可选）

配合 `totknavi/` 构建的本地定位服务 TOTKNavi.exe（连接 Ryujinx / Eden 模拟器内存读取坐标，默认端口 8766），在线地图可实时显示你在游戏里的位置：红点 + 轨迹 + 金色引导线 + 距离读数，支持自动跟随切层、到达自动清除。

**TOTKNavi-GUI**（桌面定位导航程序，Wails 构建）：启动即秒锁定位（known 快路径），侧边栏四页——实时定位（坐标/层/锁定来源状态卡）、导航目标（与地图双向同步，可清除）、存档进度（21 类收集进度）、设置；点「开始定位」后自动打开地图并跟随玩家。

**注意事项**（发布包内 `README.md` 有完整版）：
- **解压到纯英文路径**——路径含中文会导致程序无法正常运行（用户实测）
- 先启动模拟器并进入游戏（站在大地图上），再点「开始定位」
- 程序只读模拟器内存，不注入不改游戏；被杀毒拦截时加白名单即可

> 导航程序是**独立产品线**（Releases 里 `totknavi-vX.Y.Z` 前缀），版本号不跟地图走；手机镜像需要本地离线地图包（`totkmap-vX.Y.Z.zip`），解压到 `TOTKnavi.exe` 同目录即可。

## 核心功能

一句话简介 + 15 项能力速览，完整说明见 [docs/FEATURES.md](docs/FEATURES.md)。

| 功能 | 说明 |
|---|---|
| 三层地图 | 天空 / 地上 / 地下一键切换，各有独立的标点、地名与瓦片 |
| 高清瓦片 | 游戏内等高线地形风格，1:1 像素仍清晰 |
| 多图层同显 | 五大类任意勾选组合，每组一键全选 / 清空 |
| 官方地名 | 1,312 处官方中文地名直接印在地图上，随缩放分层显隐 |
| 龙的轨迹 | 四条龙官方 ROMFS 轨道，实线当前层 / 虚线另一层 |
| 官方大世界宝箱 | 1,334 个官方宝箱分层显示，开关与进度均可用 |
| 存档同步 | 本地解析 `progress.sav`，21 类进度实时刷新 |
| 探索度面板 | 「探索 / 任务 / 收集 / 讨伐」四大组双列展示，带进度徽标 |
| 中英双语 | 设置面板一键切换，点位显示官方英文名 |
| 材料收集 | 110 种材料 44,279 个刷点，聚合显示 + 数量徽标 |
| 材料详情卡 | 高清图标 + 用途标签 + 导航 / 收集 / 标记三按钮 |
| 搜索定位 | 按神庙 / 地名 / 任务 / 物品名搜索，回车直达 |
| 完成与自定义标记 | 标点可标完成，空白处可加个人标记 |
| URL 深链 | `?actor=` 直达刷点，`?q=` 自动搜索 |
| 移动端适配 | 窄屏收起面板，触控缩放，详情卡变底部抽屉 |

## 数据内容

- **探索收集**：神庙 120、鸟望台 15、龙之泪 12、克洛格 742、双倍克洛格 98、魔犹伊 147、设计图石板 1、官方大世界宝箱 1,334
- **设施地点**：村庄 10、驿站 17、大妖精之泉 4、女神像 14、古代研究所 4、神殿 1、地洞入口 36、洞穴入口 189、井 58、烹饪点 63
- **材料刷点**：植物/蘑菇/水果/昆虫/鱼/矿岩 6 大类共 110 种、44,279 个点位
- **地名**：官方中文地名 1312 处（含同名多坐标点，如河流/山脉分段标注）

## 已知限制

- 区域为按官方区域中心点的近似归属，个别边界点可能偏差
- 部分材料点位为社区数据，冷门物品可能保留英文名
- z7 瓦片未纳入仓库（EdgeOne 文件数限制），最大缩放到 z7 尺寸由 z6 瓦片 2× 缩放实现（清晰度等价 z6）
