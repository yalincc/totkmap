# TOTKMAP · 塞尔达传说：王国之泪 互动地图

《塞尔达传说：王国之泪》简体中文互动地图，支持天空/地上/地下三层切换、多图层同显、收集进度追踪、材料刷点查询与实时角色导航。

## 直接使用

用浏览器打开 **`index.html`** 即可，无需服务器。

在线版：**https://totk.yalin.site/**

> 完成进度、自定义标记、图层选择自动保存在浏览器本地存储中，关页不丢。

## 实时角色导航（可选）

配合 `live-go/` 下的本地定位服务 TOTKNavi.exe（连接 Ryujinx 模拟器内存读取坐标，默认端口 8766），在线地图可实时显示你在游戏里的位置：红点 + 轨迹 + 金色引导线 + 距离读数，支持自动跟随切层、到达自动清除。

**TOTKNavi-GUI**（桌面定位导航程序，Wails 构建）：启动即秒锁定位（known 快路径），侧边栏四页——实时定位（坐标/层/锁定来源状态卡）、导航目标（与地图双向同步，可清除）、存档进度（20 类收集进度）、设置；点「开始定位」后自动打开地图并跟随玩家。

## 核心功能

| 功能 | 说明 |
|---|---|
| 三层地图 | 天空 / 地上 / 地下一键切换，各自独立的标点、地名与瓦片；左侧层按钮可锁定当前层 |
| 高清瓦片 | 游戏内等高线地形风格瓦片，按层选格式（WebP q80），最大 1:1 像素仍清晰 |
| 多图层同显 | 位置 / 收集 / 装备 / 地点 / 怪物五大类可任意勾选组合，一键全选 / 清空 |
| 官方地名 | 1312 处官方中文地名直接印在地图上（objmap Location 坐标），随缩放分层显隐，自动防重叠 |
| 存档同步 | 上传《王国之泪》`progress.sav`，自动读取游戏真实收集进度（鸟望台、神庙、树根、龙之泪、克洛格、魔犹伊等），解析全程本地完成；内置同步存档 · 帮助（模拟器/游戏版本、存档位置、加载技术） |
| 探索度面板 | 加载存档后显示关键收集项完成进度与金色进度条，点击展开/收起 |
| 材料收集 | 110 种材料共 44,279 个刷点（地表/地底/天空全覆盖），勾选即在地图上显示；supercluster 聚合 + 数量徽标，最大缩放到 z7 尺寸时逐点显示、每个材料点可点 |
| 材料详情卡 | 256×256 高清图标 + 用途标签（升级素材/料理材料/强化材料）+ 导航/收集/标记完成三按钮；收集后自动定位下一未采集点 |
| 材料性能优化 | 聚合半径随缩放级别动态调整（100%=96px → 800%=128px）+ 移动防抖，地下 12000+ 刷点场景拖动依旧流畅 |
| 搜索定位 | 按神庙/地名/任务/物品名搜索，回车直达并居中放大；材料 Tab 内独立搜索 |
| 完成标记 | 点击标点查看详情，可标记为已完成，进度保存在本地 |
| 自定义标记 | 在地图空白处添加带名称的个人标记 |
| URL 深链 | `?actor=<物品名>` 直达材料刷点，`?q=<关键词>` 自动搜索 |
| 移动端适配 | 窄屏默认收起面板，触控缩放平移，详情卡自动变底部抽屉 |

## 数据内容

- **探索收集**：神庙 120、鸟望台 15、龙之泪 12、克洛格 742、双倍克洛格 98、宝箱 191、魔犹伊 147、设计图石板 1
- **设施地点**：村庄 10、驿站 17、大妖精之泉 4、女神像 14、古代研究所 4、神殿 1、地洞入口 36、洞穴入口 189、井 58、烹饪点 63
- **材料刷点**：植物/蘑菇/水果/昆虫/鱼/矿岩 6 大类共 110 种、44,279 个点位
- **地名**：官方中文地名 1312 处（含同名多坐标点，如河流/山脉分段标注）

## 已知限制

- 区域为按官方区域中心点的近似归属，个别边界点可能偏差
- 部分材料点位为社区数据，冷门物品可能保留英文名
- z7 瓦片未纳入仓库（EdgeOne 文件数限制），最大缩放到 z7 尺寸由 z6 瓦片 2× 缩放实现（清晰度等价 z6）
