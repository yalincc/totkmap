# TOTKNavi · 王国之泪实时定位导航

《塞尔达传说：王国之泪》（TOTK）实时定位工具：在网页地图上显示你在游戏里的实时位置，**走路、传送都跟随**。支持 **Ryujinx** 与 **Eden**（Yuzu 分支）双模拟器（TOTK 1.2.1 测试）。

网页地图：<https://totk.yalin.site>

![platform](https://img.shields.io/badge/platform-Windows-blue) ![emulator](https://img.shields.io/badge/emulator-Ryujinx%20%7C%20Eden-success)

---

## 功能

- **实时跟随（v2.2.0 加强）**：只读模拟器内存，在网页地图上实时显示玩家坐标；**跑动与传送连续跟随**，掉锁后约 0.2 秒自动重锁
- **秒锁定位**：指针链 + 记忆地址直接定位，启动即锁；失效时自动全内存扫描兜底
- **自动重锁**：传送、读图、进神庙、游戏重启都自动恢复，无需手动操作
- **存档进度看板**：自动读游戏存档，显示神庙 / 鸟望台 / 树根 / 克洛格 / 魔犹伊 / 卡邦达立牌进度
- **手机镜像**：手机与电脑同一 WiFi 扫码即可在手机上跟随（可选 HTTPS，防息屏）
- **一键诊断**：出问题时点「导出诊断包」，把系统信息与日志打包发给开发者
- **只读内存**：不注入、不修改游戏、不联网上传任何数据

## 下载与使用

1. 从 [Releases](https://github.com/yalincc/totkmap/releases) 下载最新版 `TOTKNavi-vX.Y.Z.zip`
   （需要**离线地图**的用「手机镜像整合版」，手机无网也能用）
2. ⚠️ **解压到纯英文路径**——路径含**中文或空格**会导致程序无法正常启动/运行
3. 先启动模拟器（Ryujinx / Eden），**进入游戏**（站在大地图上，不要开菜单）
4. 双击 `TOTKnavi.exe`，点 **▶ 开始定位**
5. 锁定成功后自动打开网页地图，红点跟着你走

> 首次运行 Windows 可能弹防火墙提示，点允许——它只在本机 `127.0.0.1:8766` 起 HTTP 服务给网页读坐标，不对外暴露。

## 常见问题

**Q: 解压后程序打不开 / 双击一闪就没了？**
A: **最常见的原因是解压路径含中文**（或空格）。把整个文件夹移到纯英文路径（例如 `D:\TOTKnavi\`）再运行。

**Q: 点开始后一直「等待模拟器进程」？**
A: 确认模拟器已经启动、并且游戏已经进到大地图（停在主菜单不行）。工具按进程名探测，别改模拟器程序名。

**Q: 一直「扫描中」不出坐标？**
A: 首次使用或偏移失效时会做一次全内存扫描，需要 5~15 秒；扫到后会记住，之后都是秒锁。

**Q: 传送 / 读图后红点不动？**
A: 会自动重新锁定，通常不到 1 秒就恢复跟随，无需手动操作。

**Q: 网页地图看不到红点？**
A: 确认工具顶栏显示「坐标流同步中」，然后刷新 <https://totk.yalin.site>。本机端口 8766 不能被其他程序占用。

## 数据与隐私

- 所有操作都在你本机进行：读模拟器内存、读本地存档、起一个 localhost HTTP 服务
- 不收集任何数据、不上传任何信息
- 「打开地图」按钮只是用浏览器打开公开网页 <https://totk.yalin.site>

## 要求

- Windows 10 / 11（64 位）
- Ryujinx（Canary）或 Eden（Yuzu 分支）
- TOTK 游戏本体（Switch 版，1.2.1 测试）
- 网页地图需要联网（离线请用「手机镜像整合版」）
