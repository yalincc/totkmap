# live-eden

《王国之泪》（The Legend of Zelda: Tears of the Kingdom）在 **Eden 模拟器**（Yuzu 系，GPLv3 开源）下的实时定位导航程序（GUI + 引擎 + 在线地图联动）。

## 功能

- 实时读取游戏内玩家坐标（东 X / 北 Y / 高 Z），输出与游戏 HUD 一致的坐标口径（`Z_stored = 高度 + 105`，内存序 `(X, Z_stored, Y_north)`，已三重验证）
- 定位方式（自动切换，无需手动干预）：
  - **known 秒锁**：记住玩家槽绝对地址，同会话毫秒级锁定；Eden 内存布局稳定时跨重启也直接命中
  - **坐标校准（v1.4.0）**：秒锁失效时，在 GUI 输入游戏内地图显示的坐标（按 `-` 打开地图，右下角显示），全内存三轴精确匹配定位真槽，命中即锁并写入 known（本机之后秒锁）
  - **全量扫描兜底**：按存档锚点窗口扫描（known/校准都失败时）
  - **自愈**：锁读数停滞 / 传送 / 场景切换自动处理，站桩不误换锁
- 存档进度解析：神庙 / 克洛格 / 鸟望台 / 树根等 20 类收集进度卡片
- GUI（TOTKNavi-Eden.exe）内置引擎，一键开始定位；网页地图 https://totk.yalin.site/ 红点实时跟随
- HTTP API：`http://127.0.0.1:8766/pos`（JSON 坐标）、`/rescan`（强制重扫）、`/set-coords`（坐标校准）

## 使用

1. 启动 Eden 模拟器并进入《王国之泪》游戏
2. 运行 `TOTKNavi-Eden.exe`（GUI），点击「开始定位」
3. 正常情况秒锁（⚡）；若一直"定位中"，用「坐标校准」卡片：游戏内按 `-` 打开地图 → 右下角坐标填入 X/Y/Z → 提交校准 → 约 15 秒后锁定
4. 定位成功后红点在地图网页 https://totk.yalin.site/ 实时跟随

## known 地址与内存布局（常见问题）

**known 记住的是"绝对内存地址"，绑定本机 + 当前内存布局**：

- **重启游戏**：同一台机器、同一个 Eden 版本、同一个 DRAM 设置下，地址稳定，秒锁持续有效；万一失效，重新坐标校准一次（15 秒）即可
- **修改 Eden 的 DRAM 内存设置（如 6GB ↔ 8GB）**：guest 内存布局会变，**所有 known 地址全部失效**。改回原设置或重新坐标校准一次
- **换电脑 / 换 Eden 版本**：绝对地址必然不同。**每台电脑首次使用 = 坐标校准一次（15 秒）→ 之后永久秒锁**。这是 Eden 的硬约束（guest 内存碎片化、无固定块锚点，无法像 Ryujinx 那样跨机器 rebase）

## 目录

- `engine/`：定位引擎（Go 源码，编译产物 `xnavi-eden.exe`）
- `TOTKNavi-Eden.exe`：GUI 导航程序（v1.4.0，内置引擎）
- `xnavi-eden.exe`：独立引擎（GUI 自动调用，也可命令行单独运行：`xnavi-eden.exe 8766`）
- `probe/`：内存诊断与探针工具（开发用）
- `log/`：历史运行日志（开发排查用）
- `backup/`：历史版本备份
