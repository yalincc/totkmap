# totknavi-pc

《王国之泪》**PC 重编译版**（TotK Recomp）的定位程序。

与 `totknavi/`（模拟器版）并列的独立工程：模拟器版读 Eden/Ryujinx 里的 guest 内存，
这里读 `totk.exe` 自己。

---

## 怎么用

进目录，双击：

| 文件 | 作用 |
|---|---|
| `watch.bat` | 控制台看坐标 + 朝向 |
| `serve.bat` | 起服务并打开网页地图 |

手动命令（**一行一行敲，别把 cd 和 exe 粘一起**）：

```
cd /d E:\WorkSpace\TOTKmap\totknavi-pc
totknavi-pc.exe --watch
```

**首次启动后请在游戏里走两步** —— 程序会打印「候选 0x... 请移动角色验证」，
走两步后出现「移动确认成功」才算完全锁定。

## 定位机制（与模拟器版同构）

只做三件事，与 `totknavi/core_totk.go` 一致：

1. **存档锚点窄窗扫描**：读 `profile/save-tx/work/slot_XX` 的玩家坐标，
   从 120m 窗口开始扫 → 失败放 400m → 再失败 3000m
2. **移动确认**：锁定候选后，该槽坐标相对锁定时刻位移 0.5~150m 即判定真身；
   若主锁没动而候选里有动的，走动仲裁切过去
3. **死守不退**：锁定后读不到重试 3 次 → hold 上一帧，**绝不主动重扫**

> 存档路径有坑：游戏运行中新档写在 `save-tx\work`，`save\` 要等提交才更新。
> 读错地方会拿到几天前的旧档，锚点完全对不上。

## PC 版的先天优势

| | 模拟器版 | PC 版 |
|---|---|---|
| 主模块基址 | 由 arena 推演，每会话变 | **固定 `0x7000000000`** |
| 反解换算常数 K | 需要 | **不需要** |
| 扫描范围 | 1.7GB | 1.2GB（主模块 + exe 数据段 + 主堆） |
| 单次扫描 | 0.9 秒 | **0.7 秒** |

## 朝向（附加能力）

`/pos` 额外输出 `heading`（北=0°、东=90°），从坐标前 `0x30` 处的 3×4 变换矩阵**第三列取反**得到。
这是真实朝向，不是位移推算。模拟器版没有这个（其判据查的 `-0x24` 布局与 PC 版差 `0x0C`，永远不命中）。

## 已知限制

- Recomp 是早期版本（0.1.6），升级后段布局可能再变。主模块基址变了看 `logs\totk.log` 的 `loaded main at`
- 扫描依赖存档锚点：存档太久（跑出去几公里没存）会导致锁错，此时用 `--coords X Y Z` 报当前坐标
- `layer`（天空/地表/地底）暂返回 `null`
