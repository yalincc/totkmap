# TOTKNavi · 王国之泪实时定位导航

《塞尔达传说：王国之泪》（TOTK）实时定位工具，在网页地图上显示你在游戏里的位置，走路跟随。支持 **Ryujinx** 模拟器（TOTK 1.2.1 / Ryujinx 1.3.351 测试）。

网页地图：<https://totk.yalin.site>

![platform](https://img.shields.io/badge/platform-Windows-blue) ![emulator](https://img.shields.io/badge/emulator-Ryujinx-success)

---

## 功能

- **实时跟随**：只读模拟器内存，在网页地图上显示玩家坐标，随走路实时移动
- **秒锁定位**：记住的偏移直接定位，启动即锁（约 1 秒）；偏移失效时自动全内存结构扫描兜底，锁到后自动更新偏移
- **自动重锁**：传送、读图、游戏重启都自动重新锁定，无需手动操作
- **存档进度看板**：自动读游戏存档，显示神庙/鸟望台/树根/克洛格/魔犹伊/卡邦达立牌进度
- **深色 GUI**：Wails 写的 Windows 桌面界面，状态一目了然
- **一键诊断**：出问题时点"导出诊断包"，把系统信息和日志打包发给开发者
- **只读内存**：不注入、不修改游戏、不联网上传任何数据

## 下载与使用

1. 从 [Releases](https://github.com/yalincc/totkmap/releases) 下载最新版 `TOTKNavi-vX.Y.Z.zip`
2. 解压到任意目录（路径不要有中文/空格更稳妥）
3. 先启动 Ryujinx，进入游戏（站在海拉鲁大地上，别开菜单）
4. 双击 `TOTKNavi-GUI.exe`
5. 点 **▶ 开始定位**
6. 秒锁成功后自动打开网页地图；第一次用若偏移失效，在游戏里走两步让程序确认坐标是活的
7. 在网页地图上就能看到自己的红点，跟着走就行

> 首次运行 Windows 可能弹防火墙提示，点允许——它只在本机 `127.0.0.1:8766` 起 HTTP 服务给网页读坐标，不对外暴露。

## 常见问题

**Q: 点开始后一直"等待模拟器进程"？**
A: 确认 Ryujinx 已经启动并且游戏已经进到大地图（在主菜单里不行）。工具按进程名 `Ryujinx.exe` 探测，别把模拟器改名。

**Q: 一直"扫描中"不出坐标？**
A: 首次使用且偏移失效时会全内存扫描，需要 5-15 秒。扫到后自动写入偏移文件，之后秒锁。

**Q: 网页地图看不到红点？**
A: 确认工具顶栏显示"坐标流同步中"，然后刷新网页 https://totk.yalin.site 。本地端口 8766 不能被别的程序占用。

**Q: 传送/读图后红点不动？**
A: 会自动重新锁定，几秒内恢复跟随，无需手动操作。

## 数据与隐私

- 所有操作都在你本机进行：读模拟器内存、读本地存档、起一个 localhost HTTP 服务
- 不收集任何数据，不上传任何信息
- "打开地图"按钮只是用浏览器打开公开网页 <https://totk.yalin.site>

## 要求

- Windows 10 / 11（64 位）
