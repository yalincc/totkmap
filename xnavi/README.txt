======================================================
  TOTKNavi v3.0.0 · 王国之泪实时定位导航程序
======================================================

【这是什么】
电脑上的定位导航工具：只读模拟器内存，把游戏中林克的
实时位置显示在网页地图上（支持 Ryujinx / Eden 双模拟器）。
网页地图：https://totk.yalin.site

【快速开始（电脑）】
1. 先启动模拟器（Ryujinx 或 Eden）并进入游戏
   （确保角色站在大地图上，不要停留在主菜单或设置界面）；
2. 双击运行 TOTKnavi.exe，点击右上角「▶ 开始定位」；
3. 第一次定位可能需要在游戏里走两步让程序确认移动；
   定位成功后会自动打开网页地图并直接开启跟随，跟着走即可。

【手机/平板跟随（局域网镜像 + 防息屏）】
本导航包不含庞大的离线地图瓦片，手机映射建议配合离线地图包：
1. 下载地图整合包 TOTKNavi-v3.0.0-MapBundle.zip 或地图包；
2. 把里面的 app 文件夹放进本目录（与 TOTKnavi.exe 同目录）；
3. 电脑网页地图点右下角手机图标扫码打开；
4. 【手机防息屏（两种方案二选一）】：
   方案 A（推荐 · 极简）：直接安装本目录自带的 xnavi-mirror.apk
   （仅 18KB，只申请网络权限），打开后粘贴镜像链接，屏幕保持常亮！
   方案 B（浏览器原生长显）：按 certs 目录指引安装根证书，并在软件设置
   勾选「手机防息屏（Https）」，之后用 https 链接访问。

【常见问题与速查】
· 点开始定位没反应？——确认模拟器已进入 3D 游戏世界（不能在主菜单）。
· 网页地图看不到红点？——浏览器直接打开 http://127.0.0.1:8766/pos
  能看到一串 JSON 数据 = 定位服务正常，多为浏览器代理冲突（把 127.0.0.1 加入代理白名单）；
  打不开 = 核心未启动或端口被占，在 GUI 实时日志查看报错。
· 详细使用教程与问答 —— 请看 GUIDE.md（记事本或 VSCode 均可打开）。
· 进阶排查自检步骤 —— 请看 TROUBLESHOOTING.md。

【安全声明】
只读模拟器内存，不注入、不修改游戏、不联网上传任何隐私数据。
