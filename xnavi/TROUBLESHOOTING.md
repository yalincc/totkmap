# TOTKnavi 问题排查与速查表（TROUBLESHOOTING）

**适用版本**：TOTKnavi v3.0.0。
**排查原则**：开着 TOTKnavi、界面显示状态时做排查（不要关掉窗口再测，关窗口会导致后台核心停止、端口释放，测出假故障）。

---

## 0. 启动流程六步对照表（看卡在哪一步）

日志在 GUI 窗口底部日志栏或目录下的 `xnavi-gui-core.log`，从上往下比对：

| 步骤 | 正常日志表现 | 异常日志表现 | 解决办法 |
|---|---|---|---|
| ① HTTP 服务 | `API -> http://127.0.0.1:8766/pos` | 端口被占用无法绑定 | 见下文 §1 自检，结束残留的 `totknavi-core.exe` 进程 |
| ② 模拟器附加 | `[platform] auto-detected: Eden` 或 `Ryujinx` | `waiting for Ryujinx / Eden` | 先开启模拟器并载入进入大地图，不要停在标题画面 |
| ③ 游戏存档 | `[progress] save=... slot_XX` | `waiting for save anchor (press [+] in game)` | 在游戏里按 `+` 键手动存一次档，或在 GUI 点【选择存档】 |
| ④ 内存扫描 | `[scan] ... 发现新鲜存档 / 扫描锚点窗口` | `[lost]` 模拟器断开 | 检查模拟器是否崩溃，在游戏里走两步让角色处于可控状态 |
| ⑤ 走动锁定 | `[verify] -> [lock] ... 真身锁定【已完全锁定】` | 长时间停在 `[verify]` | 主角在游戏里随便跑动两三步，让系统确认坐标活跃真身 |
| ⑥ 网页连入 | 网页打开，红点实时跟随 | 网页转圈或提示离线 | 打开 `https://totk.yalin.site`，检查代理软件设置 |

## 1. 30 秒三步自检（精确定位根源）

保持 `TOTKnavi.exe` 处于运行状态，按以下 3 步排查：

### 第一步：8766 端口是否在监听
键盘按 `Win + R` 键，输入 `cmd` 回车，粘贴运行：
```cmd
netstat -ano | findstr 8766
```
- 看到 `LISTENING` 行：记录行末的数字（进程 PID），进行第二步；
- 什么都没有：说明核心未启动（检查是否误点了停止定位或杀软误杀拦截）；
- 看到 `TIME_WAIT`：属于正常探活现象，不用理会。

### 第二步：确认监听进程是否为核心
在 CMD 中运行（把 `12345` 换成上一步记下的 PID）：
```cmd
tasklist /fi "pid eq 12345"
```
- 显示 `totknavi-core.exe`：说明底层服务运行正常，做第三步；
- 显示其他程序：说明 8766 端口被别的软件抢占，关闭抢占的软件后重启定位器。

### 第三步：浏览器直连测试
在电脑浏览器（先关闭梯子/代理软件）中直接访问：
```
http://127.0.0.1:8766/pos
```
- 浏览器显示包含 `{"ok":true,"gx":...}` 的 JSON 数据：说明**定位核心与网络完全正常**！
  此时网页端地图打不开红点，100% 是浏览器安装的某些脚本或全局代理拦截了本地 `127.0.0.1`，把 `127.0.0.1` 与 `localhost` 加入代理白名单即可。
- 浏览器提示拒绝连接：检查 Windows 防火墙或杀毒软件是否拦截了 `totknavi-core.exe`。

## 2. 常见问题对号入座

### Q: 点了开始定位，一直卡在「等待模拟器进程」？
- 确认模拟器（Ryujinx 或 Eden）已经在运行，且游戏已经载入进入 3D 世界（不是游戏启动菜单）；
- 确认模拟器没有被改名（进程名必须是 `Ryujinx.exe` 或 `eden.exe`）；
- 如果同时开着两个模拟器，请在顶部下拉菜单中明确指定要连接的模拟器。

### Q: 传送后红点不动了？
- v3.0.0 已全面优化传送门槛（>=50m 无论远近自动接管）；
- 如果在神庙内部，红点会智能锚定在神庙入口门口，出庙或传送后会自动恢复大世界跟随；
- 若偶发迷失，点击界面左下角「🧭 坐标校准」，输入游戏右下角 HUD 坐标或点击预设按钮即可秒级恢复。

### Q: 手机扫码后打不开地图或显示灰块？
- 手机与电脑必须连接**同一个 WiFi 路由器**（不能一个是 4G/5G 一个是 WiFi）；
- 手机镜像必须有离线地图包（即本目录下必须存在 `app` 文件夹，内含 `index.html`）。

### Q: 手机屏幕总是几秒就自动黑屏熄屏？
- 安卓手机用户强烈推荐直接安装本目录附带的 **`xnavi-mirror.apk`**（仅 18KB），粘贴镜像网址打开即可永久常亮；
- 或者按 `certs/README.md` 指引安装证书，在设置勾选「手机防息屏（Https）」。
