## 核心功能

- **三层立体实时跟随**：只读模拟器内存，在网页地图上精准显示林克坐标，天空、地上、地底三层世界平滑切换与深穴自由穿梭
- **零重扫传送接管**：大世界与近距离传送（>=50m，如鸟望台、神庙相依点）瞬移直读更新，告别旧版频繁丢锁与卡死
- **神庙入口锚定防误判**：内置 152 座神庙与 15 座鸟望台官方坐标，进出神庙试炼场智能锚定，杜绝中心盒范围误锁
- **20 类存档进度看板（v3.0.0）**：自动读取游戏存档，实时呈现鸟望台、神庙、树根、克洛格、魔犹伊、贤者遗志、大型 Boss 讨伐等全量 20 项收集要素
- **4 大精确 HUD 坐标校准**：定位失败或异常时，一键填入游戏内右下角原生 HUD 坐标（预设监视堡垒鸟望台、避难所、神庙、觉醒室）
- **自动开图**：定位成功后自动在浏览器打开在线地图，并直接开启网页「跟随玩家位置」
- **深色 GUI 桌面程序**：Wails 构建的现代 Windows 桌面界面，状态、坐标、存档路径与实时日志一目了然
- **一键诊断包导出**：遇到问题时点右下角「导出诊断包」，一键打包系统环境与日志供排查
- **绝对安全**：只读模拟器内存，不注入 dll、不修改游戏文件、不联网上传任何个人隐私

## 下载与使用

1. 从 Releases 下载最新版：
   - `TOTKNavi-v3.0.0.zip` —— 纯导航版，PC 浏览器打开在线地图
   - `TOTKNavi-v3.0.0-MapBundle.zip` —— 导航 + 全量离线地图整合包，支持手机局域网离线扫码导航
2. 解压到任意目录（**路径务必为纯英文，避免中文或空格**）
3. 先启动模拟器（Ryujinx 或 Eden），进入游戏（角色站在大地图上，别停留在主菜单）
4. 双击运行 `TOTKnavi.exe`
5. 点击右上角 **▶ 开始定位**
6. 首次定位在游戏里走两步让程序确认移动真身；状态变为「已锁定」后会自动打开网页地图并开启实时跟随
7. 在网页地图上就能看到自己的红点，跟着走即可

> 首次运行 Windows 可能弹出防火墙提示，请点「允许访问」——定位器仅在本地 `127.0.0.1:8766` 开启 HTTP 服务供地图读取坐标。

## 手机/平板镜像：扫码跟随 + 防息屏

> **前提：手机映射需要本地离线地图。** 纯导航包本身不含庞大的地图瓦片文件——请下载整合包 **`TOTKNavi-v3.0.0-MapBundle.zip`**，或把地图包里的 `app` 文件夹放进 `TOTKnavi.exe` 同目录。

手机与电脑连**同一 WiFi**，电脑网页地图点右下角 📱 手机图标显示二维码，用手机扫一扫即可在手机端显示地图与红点跟随。

如果手机浏览器会自动熄屏，**安卓手机**提供两种解决措施（二选一）：

1. **安装手机专用 APP（推荐 · 最方便）**：
   解压目录自带 **`xnavi-mirror.apk`**（仅 18KB，只申请网络权限），发到安卓手机安装；打开后粘贴镜像地址，**屏幕即可永久保持常亮**！
2. **安装根证书**：
   按 `certs` 目录指引安装根证书，并在软件设置中勾选「手机防息屏（Https）」，之后手机用 HTTPS 访问即可保持屏幕常亮。

> 苹果 iOS (iPhone / iPad) 用户可直接扫码在 Safari 浏览器中打开；若嫌熄屏，可在系统「设置 → 显示与亮度 → 自动锁定」改为「永不」。

## 界面各板块说明

- **顶栏状态与控制**：
  - 模拟器选择（自动探测 / Ryujinx / Eden）
  - 打开网页地图按钮

  - 底部存档状态条：清晰展示当前生效的 slot 存档路径与修改时间
  - 【选择存档】【选择目录】【定位文件】【重新检测】快速管理按钮
- **底部：实时日志**：
  - 详细输出平台附加、扫描、锁定、传送、神庙进出等事件日志
  - 支持关键字过滤、一键清屏与导出诊断包

## 常见 Q&A

**Q: 存档进度多久刷新一次？**
A: 核心每 2 秒检测一次存档文件，当你在游戏里按 `+` 键手动存档或触发自动存档后，**≤2 秒内**看板会自动同步刷新。红点坐标则走内存直读（10Hz），完全实时。

**Q: 为什么提示「未检测到模拟器」？**
A: 请确认模拟器已启动并且已经载入游戏大地图。程序通过进程名匹配（`Ryujinx.exe` 或 `eden.exe`），请勿私自修改模拟器文件名。

**Q: 为什么网页地图看不到红点？**
A: 确认 GUI 顶栏已进入「已锁定」状态。在浏览器打开 `http://127.0.0.1:8766/pos`，若能看到 JSON 数据说明服务正常，多半是电脑开启了代理软件（梯子），请在代理软件的「绕过设置」中将 `127.0.0.1` 和 `localhost` 加入白名单。

**Q: 详细报错如何自检？**
A: 请参阅本目录下的 **`TROUBLESHOOTING.md`** 进行 30 秒三步自检。
