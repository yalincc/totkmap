# TOTKnavi · 王国之泪实时定位导航

《塞尔达传说：王国之泪》（TOTK）实时定位工具，在网页地图上显示你在游戏里的三层世界实时位置，走路跟随，游戏内21类信息同步解析看板。

网页地图：<https://totk.yalin.site>

> 快速上手请看压缩包里的 **README.txt**（记事本可直接打开）；本文件是详细用户指南。

## 核心功能

- **三层立体实时跟随**：只读模拟器内存，在网页地图上精准显示林克坐标，天空、地上、地底三层世界平滑切换与深穴自由穿梭
- **核心技术定位**：通过存档快速定位并锁定addr，实现大世界无论进神庙、传送、骑马都不会丢失地址，告别旧版频繁丢锁与卡死
- **游戏要素全标注**：游戏内超过2w+素材的地图标注和探索度相关的20+游戏要素，实现游戏和地图几乎实时同步
- **神庙入口锚定防误判**：内置 152 座神庙与 15 座鸟望台官方坐标，进出神庙试炼场智能锚定，杜绝中心盒范围误锁
- **21 类存档进度看板（v3.0.1）**：自动读取游戏存档，实时呈现鸟望台、神庙、树根、克洛格、魔犹伊、贤者遗志、大世界宝箱、大型 Boss 讨伐等全量 21 项收集要素
- **精确 HUD 坐标校准**：定位失败或异常时，一键填入游戏内右下角原生 HUD 坐标（预设监视堡垒鸟望台、避难所、神庙、觉醒室）

## 下载与使用

1. 从 [Releases](https://github.com/yalincc/TOTKmap/releases) 下载最新版：
   - **`TOTKNavi-v3.0.1.zip`** —— 纯导航版（约 8MB），PC 浏览器直接打开在线地图即可跟随
2. 解压到任意目录（**路径务必为纯英文，避免中文或空格**）
3. 先启动模拟器（Ryujinx 或 Eden），进入游戏（角色站在大地图上，别停留在主菜单）
4. 双击运行 `TOTKnavi.exe`
5. 点击右上角 **▶ 开始定位**
6. 首次定位在游戏里走两步让程序确认移动真身；状态变为「已锁定」后会自动打开网页地图并开启实时跟随
7. 在网页地图上就能看到自己的红点，跟着走即可

> 首次运行 Windows 可能弹出防火墙提示，请点「允许访问」——定位器仅在本地 `127.0.0.1:8766` 开启 HTTP 服务供地图读取坐标。

## 手机/平板镜像：扫码跟随 + 防息屏

> **前提：手机映射需要本地离线地图。** 导航包（`TOTKNavi-v3.0.1.zip`）本身不含地图文件——如需手机扫码或纯离线使用，请到 Releases 下载地图包 **`totkmap-vX.Y.Z.zip`**，解压后把里面的 `app` 文件夹放进 `TOTKnavi.exe` 同目录（两个包解压到同一目录即可）。没有它，手机扫码只会看到引导页；PC 在线地图导航则不需要这一步。

手机与电脑连**同一 WiFi**，电脑网页地图点右下角 📱 手机图标显示二维码，用手机扫一扫即可在手机端显示地图与红点跟随。

> 1. 如果手机浏览器会自动熄屏，**安卓手机**提供两种解决措施：
> - **安装手机专用 APP（推荐 · 最方便）**：
   解压目录自带 **`xnavi-mirror.apk`**，发到安卓手机安装；打开后粘贴镜像地址，**地图像看视频一样保持常亮**！
> - **安装根证书**：
   按 `certs` 目录指引安装根证书，并在软件设置中勾选「手机防息屏（Https）」，之后手机用 HTTPS 访问即可保持屏幕常亮。
> 2. 苹果 iOS (iPhone / iPad) 用户可直接扫码在 Safari 浏览器中打开；若嫌熄屏，可在系统「设置 → 显示与亮度 → 自动锁定」改为「永不」。

## 界面各板块说明

- **顶栏状态与控制**：
  - 模拟器选择（自动探测 / Ryujinx / Eden）
  - 打开网页地图按钮
  - 开始定位 / 停止定位切换按钮
- **左侧：实时同步坐标与校准**：
  - 显示当前 X 东西、Y 南北、Z 高度及所在图层（地上/地下/天空）
  - 坐标校准栏：定位偶发失败时，填写游戏右下角 HUD 三维坐标，或点击「预设」按钮一键填入地标
- **右侧：本地解析进度看板（20 类）**：
  - 呈现 20 项收集进度看板
  - 底部存档状态条：清晰展示当前生效的 slot 存档路径与修改时间
  - 【选择存档】【选择目录】【定位文件】【重新检测】快速管理按钮
- **底部：实时日志**：
  - 详细输出平台附加、扫描、锁定、传送、神庙进出等事件日志
  - 支持关键字过滤、一键清屏与导出诊断包

## 常见 Q&A

**Q: 存档进度多久刷新一次？**
A: 核心每 2 秒检测一次存档文件，当你在游戏里按 `+` 键手动存档或触发自动存档后，**≤2 秒内**看板会自动同步刷新。红点坐标则走内存直读（10Hz），完全实时。

**Q: 为什么提示「未检测到模拟器」？**
A: 请确认模拟器已启动并且已经载入游戏大地图。程序通过进程名匹配（`Ryujinx.exe` 或 `eden.exe`），请勿私自修改模拟器文件名。

**Q: 为什么网页地图看不到红点？**
A: 确认 GUI 顶栏已进入「已锁定」状态。在浏览器打开 `http://127.0.0.1:8766/pos`，若能看到 JSON 数据说明服务正常，多半是电脑开启了代理软件（梯子），请在代理软件的「绕过设置」中将 `127.0.0.1` 和 `localhost` 加入白名单。
