======================================================
  TOTKNavi v3.0.1 · 王国之泪实时定位导航程序
======================================================

【这是什么】
一款王国之泪模拟器的游戏导航，实时定位并同步游戏信息。
网页地图：https://totk.yalin.site

【快速开始（电脑）】
1. 先启动模拟器（Ryujinx 或 Eden）并进入游戏。
   （确保角色站在大地图上，不要停留在主菜单或设置界面）；
2. 双击运行 TOTKnavi.exe，点击右上角「▶ 开始定位」；
3. 第一次定位，等待提示在游戏里走两步即可秒锁定位，并打开在线地图；

【手机/平板跟随（局域网镜像 + 防息屏）】
如果需要手机映射导航，需要配合离线地图包：
1. 到 GitHub/Gitee Releases 下载地图包 totkmap-vX.Y.Z.zip（或者源码中的 app 文件夹）；
2. 解压后把里面的 app 文件夹放进本目录（与 TOTKnavi.exe 同级）：
     TOTKnavi.exe
     app/          ← 放入此文件夹
3. TOTKNavi 成功定位后，网页地图点右下角手机图标 → 扫码或手机输入局域网映射网址；

【常见问题与速查】
· 点开始定位没反应？——确认模拟器已进入 3D 游戏世界（不能在主菜单）。
· 网页地图看不到红点？——浏览器直接打开 http://127.0.0.1:8766/pos
  能看到一串 JSON 数据 = 定位服务正常，多为浏览器代理冲突（把 127.0.0.1 加入代理白名单）；
  打不开 = 核心未启动或端口被占，在 GUI 实时日志查看报错。
